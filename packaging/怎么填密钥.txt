怎么填密钥（给第一次用的人）
================================

你只需要改一个文件：跟 qqbot.exe 放在同一个文件夹里的  .env

如果这个文件夹里没有 .env，只有 .env.example，
那就先把 .env.example 复制一份，改名成 .env（去掉 .example）。
或者直接双击 启动.bat，它会自动帮你复制并打开。

用记事本打开 .env，找到下面三行，把等号后面改成你自己的值：

--------------------------------------------------
PANEL_PASSWORD=my-panel-pass
--------------------------------------------------
这是「你以后打开控制台网页时要输的密码」。
自己随便定一个，比如  wodemima123
建议用英文和数字，别用中文，别留 my-panel-pass 这个示例值。

--------------------------------------------------
DEEPSEEK_API_KEY=sk-REPLACE_WITH_YOUR_KEY
--------------------------------------------------
这是 AI 大脑的钥匙，必须去申请，不填就聊不了天。

1. 浏览器打开：https://platform.deepseek.com/api_keys
2. 注册 / 登录（手机号或邮箱都行）
3. 左侧点 "API keys" → 点 "创建 API key"
4. 复制那串以 sk- 开头的字符（只显示一次，一定马上存下来）
5. 粘到 .env 里，变成这样：
   DEEPSEEK_API_KEY=sk-你的那一长串

注意：账户里要有余额才能用。新号一般有赠送额度，
      没有的话在 "充值" 页面充几块钱就够聊很久。

--------------------------------------------------
OB_ACCESS_TOKEN=my-token-123
--------------------------------------------------
这是「机器人连 NapCat 用的暗号」。
它不需要去别的地方申请，你自己随便定一个就行，
比如  qqbot-2026-abc

但是！它必须和你后面在 NapCat 里填的 Token 一模一样。
建议现在就定下来，填完这里，等装 NapCat 的时候照着填同一个。

--------------------------------------------------


改完怎么知道对不对
================================

保存 .env，然后在这个文件夹里双击：
    启动.bat

它会先自检，把每个项目的状态打出来：
    [OK]   就是没问题
    [!!]   就是这项要改

全部 [OK] 之后它才会真的启动机器人。
如果还有 [!!]，窗口不会关，会停在那里让你看清楚问题。

也可以手动自检（在这个文件夹里按住 Shift + 右键 →
"在此处打开 PowerShell 窗口"，然后敲）：

    .\qqbot.exe --check


自检通过了，然后呢
================================

1. 机器人启动后，日志里会出现这样一行：
       本地控制台：http://127.0.0.1:8099
   浏览器打开这个地址，输入你填的 PANEL_PASSWORD 就能看到控制台界面。

2. 要让机器人真的收发 QQ 消息，还需要装 NapCat 并扫码登录，
   然后在 NapCat 里开一个 WebSocket 服务器（端口 3001、Token 和上面一致）。
   详细步骤看：使用教程.md


想先看界面、暂时不连 QQ
================================

在这个文件夹里按住 Shift + 右键 → "在此处打开 PowerShell 窗口"，敲：

    .\qqbot.exe --no-qq

这样只启动控制台，不连 QQ，可以先把人设和参数调好。


常见问题
================================

Q: 双击窗口一闪就没了？
A: 说明自检没通过（或者你双击的是项目根目录的 start.bat，
   那个是给源码模式用的）。改成双击 启动.bat，它会停下来告诉你原因。

Q: 提示 "DEEPSEEK_API_KEY：没填、填的还是占位文字"？
A: 你还没把 sk-REPLACE_WITH_YOUR_KEY 换成真的 key。

Q: 提示 401 / Authentication Fails？
A: key 不对、或者账户没余额。

Q: 控制台网页打不开？
A: 机器人得先跑起来（窗口不能关）。地址是 http://127.0.0.1:8099
   端口被占用的话，改 .env 里的 PANEL_PORT。

Q: 一直显示"重连中"？
A: NapCat 没启动，或者 NapCat 里的 Token 和 OB_ACCESS_TOKEN 不一致。
